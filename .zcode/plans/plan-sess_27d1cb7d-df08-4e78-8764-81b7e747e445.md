# Thinking Orbs Flutter 移植计划

## 概述

将 [thinking-orbs](https://github.com/Jakubantalik/thinking-orbs) React/TypeScript 库移植为 Flutter 原生实现。原项目是一个基于 HTML5 Canvas 2D 的"思考球"加载动画库，包含 6 种动画状态、2 种尺寸预设、自动明暗主题。Flutter 对应方案：`CustomPainter` + `Canvas` + `Ticker`。

## 技术映射

| 原项目 (React/TS) | Flutter 对应 |
|---|---|
| HTML5 Canvas 2D (`ctx.arc/fill`) | `CustomPainter` + `Canvas.drawCircle` + `Paint` |
| `requestAnimationFrame` 循环 | `Ticker` (via `SingleTickerProviderStateMixin`) |
| `performance.now()` 共享时钟 | `Ticker` 累计时间 + 速度乘数 |
| `IntersectionObserver` (离屏暂停) | Flutter 渲染管线已优化，可选用 `VisibilityDetector`(暂不加) |
| `document.visibilitychange` | `WidgetsBindingObserver` (`AppLifecycleState`) |
| `prefers-color-scheme` + 祖先 `data-theme` | `Theme.of(context).brightness` (Flutter 内置主题系统) |
| `prefers-reduced-motion` | `MediaQuery.disableAnimations` |
| DPR 限制为 2 | Flutter 原生处理，`Canvas` 直接使用逻辑像素 |
| `ModeOpts` (开放数字 Map) | `Map<String, double>` |

## 逐文件实现方案

### 1. `lib/src/types.dart` — 公共类型
- `enum OrbState { working, searching, solving, listening, composing, shaping }`
- `enum OrbSize { large(64.0), small(20.0) }` — 带 `pixels` 属性
- `enum OrbTheme { auto, dark, light }`

### 2. `lib/src/engine/types.dart` — 引擎类型
- `class Dot { double x, y, z, r, white; double? a; }`
- `typedef ModeDraw = void Function(Canvas canvas, double size, double t, bool dark, Map<String, double> opts)`

### 3. `lib/src/engine/core.dart` — 共享原语
从 `core.ts` 逐行移植：
- `hashD(a, b)` — 确定性哈希函数
- `fibDir(i, n)` — Fibonacci 球面格点方向
- `angleDelta(a, b)` — 最短有符号角距离
- `makeProj(yaw, tilt, cx, cy, scale)` — 返回 `Projector` 函数（旋转+倾斜+正交投影）
- `paintDots(canvas, dots, dark, rMin)` — Z 排序（远→近）后逐点绘制：`canvas.drawCircle(Offset, radius, Paint..color=Color.fromRGBO(g,g,g,alpha))`，复用单个 `Paint` 对象提升性能
- `radiusScale(size, pow)` — 次线性缩放

### 4. `lib/src/engine/profiles.dart` — 密度配置
从 `profiles.ts` 移植：
- `typedef ModeOpts = Map<String, double>`
- `scaleCounts(opts, scale)` — 对配对维度取 √scale，单独维度线性缩放
- `scaleRadii(opts, scale)` — 缩放所有半径键
- `baseProfiles` — 6 种模式的基础参数 (globe/orbits/rubik/wave/ribbon/morph)

### 5. `lib/src/engine/lattice.dart` — 球面格点三模式
从 `lattice.ts` 移植：
- `drawGlobe` — searching：经纬度点阵 + 扫描子午线（大小涟漪）
- `drawRubik` — solving：带状四分之一旋转，乱序→回放→归位
  - `Move` 类、`solveCycle()`、`applyMoves()`、`makeMoves()` 辅助函数
- `drawWave` — listening：波形穿过纬度环

### 6. `lib/src/engine/orbits.dart` — working 状态
从 `orbits.ts` 移植：
- `drawOrbits` — 倾斜轨道上的粒子（鬼影路径 + 运行粒子）

### 7. `lib/src/engine/morph.dart` — shaping 状态
从 `morph.ts` 移植：
- `drawMorph` — 圆形→三角形→方形轮廓变形
  - `smoothE()`、`polyPath()`、路径定义 (`CIRCLE`/`TRIANGLE`/`SQUARE`)
  - 沿混合轮廓均匀分布点

### 8. `lib/src/engine/ribbon.dart` — composing 状态
从 `ribbon.ts` 移植：
- `drawRibbon` — 波动缎带（平行弦沿大圆运行 + 行波扰动）

### 9. `lib/src/engine/registry.dart` — 模式注册表
- `Map<String, ModeDraw> modeDraws` — 映射 6 种模式到绘制函数

### 10. `lib/src/presets.dart` — 预设调优
从 `presets.ts` 移植：
- `Map<OrbState, String> stateToMode`
- `class Resolved { String mode; double speed; Map<String, double> opts; }`
- `resolvePreset(state, size)` — 解析预设：base profile → scaleCounts → scaleRadii → merge extra，带缓存
- `PRESETS` — 6 状态 × 2 尺寸的速度/数量/大小乘数 + 额外参数

### 11. `lib/src/orb_painter.dart` — CustomPainter
- 接收 `ValueNotifier<double>` 作为 `repaint` 信号
- `paint()` 中：读取当前时间 → `resolvePreset` → 从 `modeDraws` 取绘制函数 → 调用
- `shouldRepaint()` — 仅在 state/size/dark 变化时返回 true

### 12. `lib/src/thinking_orb.dart` — 主 Widget
`StatefulWidget` + `SingleTickerProviderStateMixin`：
- **动画时钟**：`Ticker` 驱动，手动累计时间以支持平滑暂停/恢复（暂停时保存累计值，恢复时从 0 增量继续）
- **主题解析**：`theme == auto` 时使用 `Theme.of(context).brightness == Brightness.dark`；`dark`/`light` 直接固定
- **减少动画**：`MediaQuery.disableAnimations` 为 true 时渲染静态帧 (t=0.6)
- **生命周期**：`WidgetsBindingObserver` 监听 `AppLifecycleState.paused/resumed`，后台暂停 Ticker
- **暂停控制**：`paused` 属性为 true 时停止 Ticker
- **Widget 参数**：`state`、`size`、`theme`、`speed`、`paused`、`semanticsLabel`
- 构建 `CustomPaint(painter: _OrbPainter(...), size: Size(pixels, pixels))`，外包 `Semantics(role: image, label: ...)`

### 13. `lib/thinking_orbs.dart` — 公共 API
导出 `ThinkingOrb`、`OrbState`、`OrbSize`、`OrbTheme`，以及 power-user API (`resolvePreset`、`stateToMode`、`modeDraws`)

### 14. `lib/main.dart` — Demo 应用
- 展示全部 6 种状态 × 2 种尺寸的网格
- 明暗模式切换
- 暂停/播放切换
- 速度滑块

## 关键实现细节

1. **零外部依赖**：仅依赖 Flutter SDK，与原项目零运行时依赖一致
2. **Paint 复用**：`paintDots` 中复用单个 `Paint` 对象，每帧仅更新 `color`，避免 GC 压力
3. **时间累计**：`Ticker` 回调提供 `Duration elapsed`（每次 start 后从 0 开始），通过 delta 累计实现平滑暂停/恢复
4. **数学函数兼容**：`dart:math` 的 `sin`/`cos`/`sqrt`/`atan2` 与 JS 的 `Math.*` 都是 IEEE 754 双精度，结果一致
5. **hashD 函数**：`sin(a * 12.9898 + b * 78.233) * 43758.5453` 是经典 GLSL 哈希，Dart 中完全相同
6. **Color 生成**：`Color.fromRGBO(g, g, g, alpha)` 对应原版的 `rgba(g,g,g,alpha)`

## 实施顺序

1. 初始化 Flutter 项目 (`flutter create`)
2. `engine/core.dart` + `engine/types.dart` + `engine/profiles.dart`（基础层）
3. 6 个绘制函数 (`lattice/orbits/morph/ribbon`)
4. `registry.dart` + `presets.dart`（组合层）
5. `types.dart` + `orb_painter.dart` + `thinking_orb.dart`（Widget 层）
6. `thinking_orbs.dart`（公共 API）
7. `main.dart`（Demo 应用）
8. `flutter analyze` + `flutter run` 验证
