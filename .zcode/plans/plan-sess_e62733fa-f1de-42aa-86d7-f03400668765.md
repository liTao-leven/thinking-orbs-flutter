# 自动发布到 pub.dev（GitHub Actions OIDC）

## 原理

利用 GitHub Actions 的 OIDC token 临时认证，无需长期 secret。push 一个 `vX.Y.Z` tag 时自动触发 `dart pub publish --force`，pub.dev 验证 OIDC token 中的仓库和 tag pattern 后发布。

## 前提

- 包已手动发布过（v1.0.0 / v1.0.1 已完成 ✅）
- 你是包的 uploader（✅）

## 步骤

### 1. 你在 pub.dev 后台手动配置（需浏览器操作）

打开 https://pub.dev/packages/thinking_orbs_flutter/admin ，在 **Automated publishing** 区域：

1. 点击 **Enable publishing from GitHub Actions**
2. **Repository**: `liTao-leven/thinking-orbs-flutter`
3. **Tag pattern**: `v{{version}}`
4. （可选）勾选 **Require GitHub Actions environment**，填 `pub.dev`（额外安全层，需手动审批才能发布）

### 2. 我创建 workflow 文件

新建 `.github/workflows/publish.yml`：

```yaml
name: Publish to pub.dev

on:
  push:
    tags:
      - 'v[0-9]+.[0-9]+.[0-9]+'

jobs:
  publish:
    permissions:
      id-token: write
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: subosito/flutter-action@v2
        with:
          channel: stable
          flutter-version: '3.44.0'
      - run: flutter pub get
      - run: dart pub publish --force
```

### 3. 后续发布流程

以后发新版本只需：
1. 改 `pubspec.yaml` 版本号
2. 更新 `CHANGELOG.md`
3. `git commit && git push`
4. `git tag vX.Y.Z && git push --tags`
5. GitHub Action 自动触发，pub.dev 自动发布

## 改动文件

| 文件 | 操作 |
|------|------|
| `.github/workflows/publish.yml` | 新建 |

## 不做

- 不改任何现有代码
- 不需要配置 GitHub Secrets
- 不需要 `pubspec.yaml` 版本变更

## 注意

- tag pattern `v{{version}}` 意味着 `v1.0.3` 会发布版本 `1.0.3`，版本号必须匹配
- 首次必须你在 pub.dev 后台先启用，否则 workflow 会 401 失败
- 如果你启用了 environment `pub.dev`，我会在 workflow 里加 `environment: pub.dev`
