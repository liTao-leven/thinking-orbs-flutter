# H5 演示页面 - GitHub Pages 自动部署

## 目标

将 `lib/main.dart` demo app 编译为 web (H5)，通过 GitHub Actions 自动部署到 GitHub Pages。
最终 URL：`https://litao-leven.github.io/thinking-orbs-flutter/`

## 可行性

demo app 完全兼容 web：只用 `Canvas.drawCircle`，无插件、无平台通道、无 dart:io。Flutter 3.44.0 支持 WASM，但首次部署先用标准 CanvasKit web build 保证稳定。

## 改动范围

| 文件 | 操作 | 说明 |
|------|------|------|
| `.github/workflows/deploy-web.yml` | 新建 | GitHub Action：push main 时自动构建 + 部署 Pages |
| `web/index.html` | 修改 | 标题改为 "Thinking Orbs"，meta description 改为真实描述 |
| `web/manifest.json` | 修改 | theme_color 改为 #6366F1（应用种子色），name 改为 Thinking Orbs |
| `README.md` | 修改 | "Live demo" 链接改为 GitHub Pages URL |
| `README.zh-CN.md` | 修改 | 同步更新中文版链接 |
| `pubspec.yaml` | 修改 | 版本升至 1.0.2 |

## 详细步骤

### 1. 创建 GitHub Action (`.github/workflows/deploy-web.yml`)

- **触发**：push 到 `main`（或手动 dispatch）
- **权限**：`contents: read` + `pages: write` + `id-token: write`
- **步骤**：
  1. Checkout 代码
  2. Setup Flutter 3.44.0 (stable)
  3. `flutter pub get`
  4. `flutter build web --release --base-href="/thinking-orbs-flutter/"`
  5. Upload `build/web/` 为 Pages artifact
  6. Deploy to GitHub Pages

### 2. 优化 `web/index.html`

```html
<title>Thinking Orbs - Flutter Demo</title>
<meta name="description" content="Dotted thought-orb loading indicators for AI & agent UIs. Six animated states, two sizes.">
```

### 3. 优化 `web/manifest.json`

- `name`: "Thinking Orbs"
- `theme_color`: "#6366F1"
- `background_color`: "#1C1B1F"（暗色背景，与 demo 默认主题一致）

### 4. 更新 README 的 Live Demo 链接

英文版：
```
[✨ Live demo](https://litao-leven.github.io/thinking-orbs-flutter/) - six states, two sizes, running in your browser.
```

中文版：
```
[✨ 在线演示](https://litao-leven.github.io/thinking-orbs-flutter/) - 六种状态、两种尺寸，浏览器中直接体验。
```

### 5. Bump 版本 + CHANGELOG

- `pubspec.yaml` -> 1.0.2
- `CHANGELOG.md` 新增 1.0.2 条目

### 6. 提交、推送、打 tag

- `git add -A && git commit`
- `git push origin main`
- `git tag v1.0.2 && git push --tags`
- GitHub Action 自动触发构建

### 7. 验证

- 在 GitHub Actions 页面确认 workflow 运行成功
- 访问 `https://litao-leven.github.io/thinking-orbs-flutter/` 确认页面加载
- 确认六态动画正常显示

## 注意事项

- GitHub Pages 首次需在 Settings -> Pages 中选择 "GitHub Actions" 作为 source（Action 部署时如未配置会提示）
- `--base-href` 必须是 `/thinking-orbs-flutter/`（带尾部斜杠），否则资源 404
- 不修改 `lib/` 下任何代码，demo app 本身已 web-ready
- 不需要改 `.gitignore`，`build/` 已被忽略，CI 中临时构建
