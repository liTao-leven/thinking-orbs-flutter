# 添加本地演示 GIF（README 主图）

## 目标

用 **本仓库 Flutter demo 录屏** 生成一张本地 GIF，展示 **暗色主题下 6 个 large（64px）状态网格**，替换 README 顶部外链 JS GIF。

## 范围

**做：**
- 在 macOS 上运行 demo app
- 录制并裁切 Large 网格区域
- 用 ffmpeg 转成优化 GIF
- 落到 `assets/demo/`
- 更新 `README.md` 引用本地路径，去掉 “JS 版本” 免责声明

**不做：**
- 亮色主题 / 小尺寸 / 分状态 GIF
- 自动录屏脚本
- 改 demo UI 或 `pubspec.yaml` assets（README 静态资源无需注册）

## 产出文件

| 路径 | 说明 |
|------|------|
| `assets/demo/demo-large-dark.gif` | 主演示 GIF（目标约 400–800KB，尽量 &lt; 2MB） |
| `README.md` | 改为引用本地 GIF |

可选（若中间产物有用）：`assets/demo/demo-large-dark.mov` 可保留或删掉，不强制入库。

## 实现步骤

### 1. 启动 demo（macOS）

```bash
cd /Users/litao/Documents/thinking-orbs-flutter
flutter run -d macos
```

确认：
- 暗色主题（默认 `ThemeMode.dark`）
- 速度 1.0×、未暂停
- 窗口足够大，Large 六宫格完整可见

### 2. 录屏

- 用 macOS 快捷键 `⌘⇧5`（或 QuickTime）**选区录制**
- 尽量只框住 **「Large · 64px」标题 + 3×2 orb 卡片网格**
- 避开 AppBar、Controls、Small 列表
- 录 **3–4 秒** 循环（动画完整一圈即可）
- 保存为临时文件，例如 `/tmp/thinking-orbs-raw.mov`

### 3. ffmpeg 转 GIF

先确认本机有 `ffmpeg`；没有则 `brew install ffmpeg`。

推荐命令（可微调 scale / fps）：

```bash
ffmpeg -y -i /tmp/thinking-orbs-raw.mov \
  -vf "fps=12,scale=500:-1:flags=lanczos,split[s0][s1];[s0]palettegen=max_colors=64:stats_mode=diff[p];[s1][p]paletteuse=dither=bayer:bayer_scale=5" \
  /Users/litao/Documents/thinking-orbs-flutter/assets/demo/demo-large-dark.gif
```

验收：
- 六态清晰可见、背景偏暗
- 文件大小合理（优先 &lt; 1.5MB）
- 循环播放无明显卡顿

若过大：降到 `fps=10` 或 `scale=420`，或 `max_colors=48`。

### 4. 更新 README

将顶部外链块：

```html
<img src="https://user-images.githubusercontent.com/209/..." ...>
```

改为：

```html
<p align="center">
  <img src="assets/demo/demo-large-dark.gif" alt="thinking-orbs Flutter demo — six states at 64px" width="500">
</p>
```

并 **删除** 这行 note：

> The GIF above shows the original JS version...

保留 live demo 链接（原版 JS）即可。

### 5. 验收

- 本地打开 `README.md` 预览（或 GitHub 预览）能加载 `assets/demo/demo-large-dark.gif`
- GIF 内容为 Flutter demo 的 large 六态网格
- `assets/demo/` 不再为空
- 不改 `pubspec.yaml`（除非后续 app 要 runtime 加载该资源）

## 风险与注意

- **需本机录屏协作**：实现时由 agent 引导启动 app；选区录屏可能需要你在屏幕上确认裁切区域（若自动化不可用）
- **无 git**：媒体仅本地落盘；日后建仓时 `assets/` 不在 ignore 中，可直接提交
- **GIF 体积**：点阵动画色阶少，palette 64 色通常足够；过大再压
